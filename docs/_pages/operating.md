After configuring your PhotoDB / AudioDB instance, you're ready to run it and use the functionlities offered by the web application. 

See how to run on [Ubuntu](/photodb/operating/operating_ubuntu.html) or [Windows](/photodb/operating/operating_windows.html).

**REMINDER:** PhotoDB and AudioDB are twin platforms, contained in one application. Depending on your data (image, audio or both) you can choose to utilize both platforms simultanously or utilize only one of the two. Since both platforms are contained in one application the operating process is the same for users intending to use only PhotoDB, only AudioDB, or both.
